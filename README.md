# Medical Clinic — Multi-specialty Website

> Conversion-focused website prototype for multi-specialty medical clinics, featuring specialty browsing and online appointment booking.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Healthcare & medical clinics

Conversion-focused website prototype for multi-specialty medical clinics, featuring specialty browsing and online appointment booking.

**Highlights**

- Booking flow by specialty, doctor and time slot
- Directory of 20 specialties and clinical staff
- Accepted health insurance plans and opening hours

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
